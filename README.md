# PMOS-Multiomics-Scripts-ALOX15B-MD-Files
This repository contains the custom Python and R analysis scripts, Molecular Dynamics files of AlOX15B-IPA complex
GSE155489_Oocytes_Analysis RNA.PY contains Python scripts of Transcriptomics data analysis
GSE155489_Cumulus Granulosa Cells_Analysis RNA.PY contains Python scripts of Transcriptomics data analysis
PRJNA794860_analysis_script RNA.R contains R Script of Transcriptomics data analysis
PRJNA685621-heatmap_analysis WES.PY contains heatmap Python script of WES data analysis
PRJNA685621-enrichment-analysis WES.PY contains enrichment Python Scripts of WES data analysis
